# 实验协议与复现

## 运行

```sh
make all test
make experiment
```

数值报告只使用 Python 标准库。原始记录在 `build/benchmark.csv`，汇总在 `build/report/`。默认固定种子 42，每组 128 次，40 组共 5,120 帧、三方法共 15,360 次评估。

不同种子与重复次数：

```sh
build/thermo benchmark --seed 2026 --trials 512 > build/benchmark-2026.csv
python3 tools/report.py build/benchmark-2026.csv --output build/report-2026
```

比较方法时使用同一批帧，不为各方法重新生成噪声。种子控制整个顺序随机流；改变循环顺序或网格会改变后续样本。不同平台数学库可能产生末位差异，不要求跨平台文件哈希相同。

## 设计

| 场景 | 变量 | 固定设置 |
|---|---|---|
| Gaussian | τ={0.12,0.3,0.75}；A={0.5,1,2}；σ/A={0,0.01,0.03,0.1} | 背景0.1，32点 |
| 背景偏差 | 输入背景比真值低/高0.02 | τ=0.3，A=1，σ=0.01 |
| 尖峰 | 索引12加0.5 | 同上 |
| 饱和 | 全信号裁剪至0.65 | 同上 |

默认估计范围 `(0.03,2)`，窗口起点4/16、宽4；全区间为4..19。压力场景针对模型失配，未把这些变形作为独立真值模型重新拟合。

## 指标

- 每条成功记录的误差：`100*(estimated_tau/true_tau - 1)`。
- RMSE：成功记录误差的均方根；bias：有符号均值；P95：绝对误差 nearest-rank 95分位。
- 拒绝率：失败记录 / 全部记录。不能把失败排除后再宣称总体准确率。
- 配对比较：固定 σ/A=0.03，只取三方法都成功的相同输入；同时展示全体失败率。

报告脚本检查重复/缺失的方法、完整参数网格、连续 trial 编号、混用种子、误差公式和无效行的空字段。失败即停止，不生成看似正常的摘要。

## 结果与解释

[已执行结果](../reports/reference/results.md)与[图表](../reports/reference/benchmark.svg)是实际程序输出。NLS 在当前加性高斯实验中收益明显，但单点尖峰与饱和会破坏其假设；对数方法可能在困难样本上拒绝更多，从而使成功子集误差显得较小。

没有进行超参数训练或真实数据调优。当前采用一个公开固定种子与明确网格，未报告置信区间，也未声称能泛化到所有探头。后续可以预先固定多种子实验协议，增加误差区间与不同失配位置，再讨论鲁棒算法收益。

## 运行代价

```sh
make benchmark-runtime
```

使用 `clock()` 统计进程 CPU 时间，对128个预生成帧循环调用各方法20,000次。输出包含总调用数、接受数、时间和 checksum，防止结果被优化掉。失败也包含在计时内，不含生成与文件 I/O。

[快照说明](../reports/README.md)记录一次主机测量。它是单次开发机结果，不是 MCU 延迟、实时性保证或跨机器性能比较。
