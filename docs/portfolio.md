# 项目展示与简历素材

本页提供基于仓库现有实现的表述。简历中的个人职责、起止时间和独立完成程度应按实际参与情况填写；运行并理解实现后再使用量化结论。

## 项目名称与介绍

**荧光衰减信号处理与可复现实验工具**  
技术栈：C11、数值优化、信号处理、Python、CSV、Make、GitHub Actions、GCC/Clang、ASan/UBSan。

围绕合成荧光单指数衰减信号，构建从数据生成、参数估计、结果有效性处理到误差评测与可视化的完整软件流程。算法核心以无动态内存的 C API 和静态库提供，命令行支持离线数据回放与批量实验。

## 可用于简历的项目要点

- 实现双窗口、对数线性回归及非线性最小二乘三种衰减参数估计方法；通过解析消去幅值，将 NLS 转化为一维有界搜索，并加入信号缩放、边界检查与统一残差诊断。
- 构建带固定种子的高斯噪声与模型失配评测，完成 **5,120帧 / 15,360次方法评估**，输出相对误差 RMSE、偏差、P95 和拒绝率，保留原始结果与复现脚本。
- 在 σ/A=3%、三方法共同成功的 **797个合成样本**上，NLS 相对 τ 误差 RMSE 由双窗口的 **14.16%降至6.22%（约56.1%）**；同时记录尖峰、饱和下的退化，明确方法适用边界。
- 将算法封装为 C 静态库与 CSV 命令行工具，实现无效帧状态输出、平滑历史复位、严格输入解析；通过数值参考、边界测试及 Linux/macOS 自动构建与消毒器检查支撑可维护性。

篇幅较短时选前三点，并把第三点的**合成数据及配对样本条件**保留。不要把相对 τ 误差写成摄氏度误差或测温精度。

## 三分钟演示顺序

1. `make all test`：展示程序、库和测试都能构建。
2. `make example`：说明 API 和业务入口分离。
3. `build/thermo simulate --frames 10 | build/thermo analyze --input -`：展示数据到结果。
4. `make experiment`：展示全体统计和方法拒绝率。
5. 打开[图表](../reports/reference/benchmark.svg)，解释 NLS 收益以及尖峰/饱和反例。

## 可展开讲解的技术问题

| 问题 | 回答线索 |
|---|---|
| 为什么等宽窗口能提取 τ？ | 单指数中等宽均值的共同几何因子抵消 |
| 为什么 log 回归在弱信号尾部表现不稳定？ | 变换放大相对噪声，非正值不能取 log，改变了噪声假设 |
| 如何减少非线性优化维度？ | 给定 τ 后幅值有闭式最小二乘解，仅搜索 log(τ) |
| 为什么不直接用更小残差宣称算法更准？ | 残差与参数误差不同，模型失配会带来有偏估计 |
| 怎样避免比较指标失真？ | 共享输入、记录失败率、明确成功子集与配对条件 |
| 怎样控制内存和异常状态？ | 固定帧数组、调用方状态、状态码、失败结果清零、CLI无效帧复位 |
| 未来怎样接入实际设备？ | 先定义时间轴与数据接口，再验证背景、噪声、模型和标定；目前未完成这些工作 |
