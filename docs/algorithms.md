# 算法细节与数值设计

实现入口：[estimator.c](../src/estimator.c)。所有时间坐标和 τ 均为无量纲量。

## 1. 双窗口比值基线

早期与晚期等宽窗口均值扣除同一背景，记为 E 与 L。对理想单指数，窗口求平均的共同几何因子抵消，因此：

```text
tau = (late_start - early_start) / 31 / (log(E) - log(L))
```

要求 `E > L > 0`。默认每窗 4 点，起点 4 和 16。计算简单，能平滑单点噪声；但晚期均值接近零时对数敏感，窗口位置也影响偏差。此方法不使用两窗之间的点估计 τ。

## 2. 对数线性回归

在整个拟合区间令 `z = log(y - b)`，拟合 `z = c + k*x`：

```text
k = sum((x - mean(x)) * z) / sum((x - mean(x))^2)
tau = -1 / k
```

等间隔索引的中心化避免直接计算大数相减形式的协方差。所有拟合点必须为正，斜率必须为负。

对数变换会改变噪声分布。小扰动近似为 `delta(log s) ≈ delta(s)/s`，弱信号尾部的对数噪声会被放大；对数域的普通最小二乘并不等价于原始信号域的加性高斯似然。该近似只是解释，不是本项目使用的修正算法。关于变换与非恒定方差的一般讨论参见 [NIST](https://www.itl.nist.gov/div898/handbook/pmd/section4/pmd452.htm)。

## 3. 原始信号域的非线性最小二乘

假定背景 b 已给定，目标为最小化：

```text
SSE(A, tau) = sum((y[i] - b - A*exp(-x[i]/tau))^2)
```

固定 τ 后，幅值是线性参数，有解析解：

```text
g[i] = exp(-(x[i] - x_start)/tau)
A_local(tau) = sum(s[i]*g[i]) / sum(g[i]^2)
SSE(tau) = sum((s[i] - A_local*g[i])^2)
```

这一步将二维优化降为一维轮廓目标（profiled objective / variable projection 思路）。实现先在 `log(tau)` 空间采样 65 点，在最小值相邻网格间做黄金分割细化；区间小于 `1e-10` 或达到 64 次迭代时结束。默认 τ 搜索范围为 `(0.03, 2)`，边界附近 `1e-6` 相对距离内标记失败。

局部幅值以拟合起点为参考，避免很小 τ 下全部指数基函数下溢。输出幅值再换算回 x=0；若外推幅值无法有限表示，则返回数值错误。NLS 允许个别扣背景后的负样本，要求整体趋势下降且拟合幅值为正。

## 4. 统一质量指标

三种方法得到 τ 后，都重新在原始信号域求该 τ 下的最优幅值，输出：

- `rmse = sqrt(SSE / point_count)`：信号残差，与 τ 参数误差不同。
- `r_squared = 1 - SSE/SST`：原始信号域拟合优度，可以为负；平坦信号无有效 SST。
- `iterations`：NLS 局部细化次数；不含粗网格计算，其他方法为 0。

因此 log 方法的输出幅值不是直接 `exp(intercept)`。统一幅值求解用于让残差指标可比较。不能用更小的残差保证更小的 τ 误差，更不能由 R² 推断真实温度准确度。

## 5. 数值与复杂度

信号先除以最大绝对值，再计算平方、协方差和残差。测试覆盖幅值 `1e-200` 到 `1e200`（背景为零），并验证尺度不变性；这不意味着大背景与极小信号叠加时仍能避免浮点消减。

| 方法 | 主要成本 | 额外存储 |
|---|---|---|
| 双窗口 | τ 估计 O(width)，统一诊断 O(N)；两次 log | 固定帧数组 |
| log | O(N)；每个拟合点一次 log | 固定帧数组 |
| NLS | O((G+K)N)，G=65，K≤64；大量 exp | 固定帧数组，无堆分配 |

公共配置限制 `1e-4 <= tau_min < tau_max <= 1e4`，这是防止不合理数值范围的接口约束，不是探头物理范围。API 是可重入的；共享滤波器或 RNG 时仍需调用方同步。

## 6. 噪声与压力场景

xorshift32 生成伪随机均匀数，再用 Box–Muller 生成高斯扰动。种子零映射到固定非零值；每点消耗两个均匀样本。该 RNG 用于实验复现，不用于密码学。不同 libm 的末位舍入可能不同。

压力测试显式注入背景偏差、单点尖峰与裁剪。尖峰恰好落在两个窗口之间，所以窗口法在该例中占优；饱和破坏单指数前段，最小二乘会受到影响。扩展鲁棒拟合前应增加不同位置/幅值的压力网格，不能只针对现有单个案例调参。
