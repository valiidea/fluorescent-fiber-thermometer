# 维护路线图

## 当前已实现

- 原始纯 C11 双窗口、平滑和文字建议演示。
- 三方法统一估计 API、无动态内存核心与静态库。
- 带固定种子的合成高斯噪声、严格 CSV 命令行与有效性处理。
- 完整参数网格、四类失配压力场景、误差/拒绝率报告及图表。
- C 边界/数值性质测试、Python 独立参考与端到端检查、跨平台 CI。
- 项目设计、接口、实验复现和简历展示材料。

## 可验证的下一步

| 方向 | 验收要求 |
|---|---|
| 鲁棒拟合 | 预先固定不同尖峰位置/幅值网格，与现有方法比较误差和拒绝率 |
| 背景联合估计 | 评估参数可辨识性、低信噪比偏差和初始化敏感性 |
| 多种子统计 | 固定实验协议，报告误差区间与失败率不确定性 |
| 非等间隔输入 | 定义时间列、验证单调性和数值条件，再扩展接口 |
| 真实数据验证 | 数据来源、设备条件和授权可追溯；与独立参考测量比较 |

这些是工作方向，不是已经实现的能力或交付承诺。真实温度标定、硬件采集与固件部署需独立需求、设备和实验数据。
