# 维护路线图

这是工作方向，不是发布日期或产品交付承诺。具体任务以 Issue 和已合并代码为准。

## 当前基础

- 纯 C11 合成数据、双窗口分析、跨帧平滑与文字反馈。
- 输入边界断言测试、设计说明和代码导读。
- 社区贡献入口、CI 与 Wiki 导航。

## 候选改进

- 按实际问题补充边界测试，例如窗口边界和极端有限数值。
- 补充可复现的教学实验，解释窗口位置与平滑权重的影响。
- 根据读者反馈扩充术语解释、图示和英文说明。

每项改进先明确教学目的与验收方法，再决定是否实现。保持少依赖、易阅读的项目规模。

## 范围边界

真实探头标定、MCU 固件、设备驱动、通信协议和闭环控制需要独立需求与证据，不属于此路线图承诺。
