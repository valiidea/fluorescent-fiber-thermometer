# 设计说明

## 从光信号到数字特征

荧光被激励后，光信号会随时间衰减。测温软件关注的是衰减形状中与温度有关的特征。一个便于理解的软件划分是：采集负责组织数据，分析负责提取特征，平滑负责降低短时波动，标定负责把特征解释为温度。

演示项目用合成数组代替采集硬件。数组里包含一个衰减分量和一个固定背景，所有数值都属于人为构造的练习数据。

## 为什么使用窗口

单个采样点可能受噪声影响。对一小段采样求平均，有助于观察局部信号水平。示例只设置两个等宽窗口：早期窗口描述较强信号，晚期窗口描述衰减后的信号。

```text
示意序列：高 ─────╲
                 ╲─────╲
                        ╲────── 低
窗口：       [早期]       [晚期]
```

窗口位置由 `demo_windows` 表达，分析模块不操作定时器。窗口重叠、越界、宽度为零或出现无效数值时拒绝分析。

## 背景扣除与衰减估计

接收信号中可能有与本次激励无关的背景。示例先减去虚构的背景值，再分别对两个窗口求平均。只有早期均值大于晚期均值，且两个值都为正时，才进入对数计算。

对于理想单指数衰减，两个位置之间的相对下降程度可以用对数比值表示。示例用归一化位置差除以两个窗口均值的对数差，得到无量纲衰减特征。这个表达式用于说明“从信号形状提取特征”，没有定义真实设备的时间尺度或测温算法。

## 平滑与有效性

平滑模块把新特征与上一次结果加权组合。新数据的权重越大，输出跟随得越快；权重越小，输出更平缓。这里使用一个简化的一阶平滑示例，便于阅读状态如何在帧与帧之间保留。

无效输入不会覆盖已有平滑值。实际软件设计中，也应把“计算得到一个数”和“这个数有效”分开表达。

## 反馈与温度映射

反馈模块只演示三个分支：信号偏低时建议增加、处于允许范围时保持、偏高时建议减少。输出是一个枚举，最终打印为文字。它不包含驱动接口、实际输出值或闭环控制策略。

温度映射需要知道某种探头和材料的特征与温度关系。本项目只说明这一阶段在整体流程中的位置，不提供数据表、拟合参数或换算实现。因此示例输出不会显示测量温度或精度指标。

## 展示范围

读者可以通过项目了解模块分工、数据结构、窗口处理、数值检查和结果平滑。硬件连接、采样调度、通信格式、持久化设置、实际标定与控制实现均不在演示范围内。
